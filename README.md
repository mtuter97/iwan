# منصة إيوان للبرمجيات التعليمية | Ewan Software Platform

منصة رقمية متكاملة تقدم حلولاً برمجية ذكية وأدوات تقنية متطورة لدعم وتطوير البيئة التعليمية، وتمكين المعلمين والمشرفين وقادة المدارس من إدارة مواردهم بكفاءة واحترافية.

---

## 🌟 مميزات المنصة

- **واجهة عصرية تفاعلية**: تصميم باللغة العربية (RTL) متوافق مع كافة الأجهزة والشاشات مع دعم الهوية البصرية الرسمية لإيوان.
- **خلفية فيديو هيرو تفاعلية**: عرض فيديو تعريفي احترافي في واجهة الموقع الرئيسية مع إمكانية التبديل إلى صورة تفاعلية.
- **عرض البرامج والأدوات**: بطاقات برامج مخصصة (إدارة المدارس، متابعة الطلاب، حوكمة الموارد، الفصول الذكية، التقارير الأكاديمية، المكتبة الرقمية).
- **إحصائيات ديناميكية**: عدادات تفاعلية تستعرض أبرز إنجازات المنصة ومستخدميها.
- **آراء الشركاء**: سلايدر تفاعلي (Owl Carousel) يستعرض تجارب قادة المدارس والمعلمين.
- **شواهد التميز ونماذج المشاريع المطبقة (MVPs)**: معرض تفاعلي يضم 7 نماذج تشغيلية حية تم تطبيقها بالفعل للمدارس مع روابط للمعاينة المباشرة.
- **نموذج تواصل مباشر**: وسيلة تواصل سريعة وفعالة لطلب العروض التجريبية والاستفسارات.

---

## 📂 شواهد ومشاريع المدارس السابقة (MVPs)

يتضمن المشروع قسماً خاصاً يستعرض نماذج تشغيلية حية جاهزة للتجربة المباشرة:
1. **منصة رصد الاختبار التشخيصي وتحليل الفاقد التعليمي** (متوسطة الفلاح بمكة المكرمة).
2. **منظومة تحليل سجل المعلم الموجّه للطلاب** (متوسطة الفلاح بمكة المكرمة — التوجيه الطلابي).
3. **أداة إدارة وتوثيق الزيارات الصفية** (متوسطة الفلاح بجدة — الإشراف التربوي).
4. **مركز قيادة التميز المدرسي ومستودع الشواهد والأدلة** (حوكمة الجودة المدرسية).
5. **منظومة تحليل نتائج التقويم الذاتي وخطة التحسين** (متوسطة الفلاح الأهلية).
6. **برنامج تحفيز — إدارة حلقات القرآن الكريم** (إدارة التسميع ونظام النقاط).
7. **منصة تتبع الإعداد المكثف لاختبارات الآيلتس** (IELTS Immersion Tracker).

## 💻 التشغيل محلياً

1. قم بتحميل أو استنساخ المستودع:
```bash
git clone https://github.com/mtuter97/iwan.git
cd iwan
```

2. تشغيل خادم محلي:
```bash
# باستخدام npx
npx serve . -l 3000

# أو باستخدام Python
python -m http.server 3000
```

3. افتح المتصفح على الرابط:
```
http://localhost:3000
```
